# Mist Live - Android TV Client

An unofficial client for [Mist Live](https://mistlive.tv/), letting viewers browse and watch live streams directly on their TV.

## Disclaimer

This is an independent, unofficial project. Streams and channel content are provided by Mist Weather Media; this project only provides the Roku client for browsing and viewing them.
